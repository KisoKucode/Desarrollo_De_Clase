# Sistema de Registro Académico

Aplicación Java desarrollada con enfoque en **Clean Code**, **SOLID** y el patrón **Repository**, que permite registrar usuarios académicos mediante una interfaz gráfica (Swing).

---

## Arquitectura

El proyecto sigue una arquitectura en capas:

- **core** → Entidades y reglas de negocio
- **data** → Persistencia (Repository Pattern)
- **ui** → Interfaz gráfica (Swing)
- **controller** → Lógica de aplicación

---

## Principios Aplicados

- SOLID
- Clean Code
- Separación de responsabilidades (SRP)
- Inversión de dependencias (DIP)
- Repository Pattern

---

## Tecnologías

- Java 17+
- Swing (UI)
- NIO (Files API)
- JUnit 5 (testing)
